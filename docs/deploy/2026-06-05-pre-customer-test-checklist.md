## 3. 本批新功能冒烟走查（部署后、给客户前，自己点一遍）

1. **空运 EES 航司分列（#1）**：运价表生成 → Air → 传 EES 报价 xlsx → 审核台「船司/航司」列日本线（KIX/NRT）有航司（CK/MU、NH…），非日本线为空（不被时刻表污染）。
2. **上传转圈（#4）**：传海运图片，上传时按钮变「AI 抽取…」+ 出现转圈 + 「AI 正在识别…数十秒勿关页」。
3. **海运 AI 抽取 + 附加费（SP2）**：运价表生成 → Sea → 传海运报价图 → 审核台出箱型价行 + **「附加费」动态列**（含→「含」、到付→「到付」、未定→橙色「稍等」并标黄待人工确认）。
4. **AI 失败不误标绿（绿标签修复）**：传一张识别不了的图 → 文件状态是黄色**「已跳过」**+ 备注原因，**不是**绿色「已抽取」。
5. **海运入库**：审核台改价 → 确认入库 → 运价管理/仪表盘能看到（附加费本版**只展示不入库**，属已知）。
6. **投标包 .xlsm 直传**：投标包自动填表 → 直接传单个 `.xlsm`（customer_a 类）→ 识别客户 → 解析 → 出成本/销售两版（前提 §1.3 DB 有运价）。
